Prefix dictionary

whisperers searches for short strings of tokens, prefixes, that make a language model do a task when they are placed in front of an input. Most read as token soup, yet with one in front of hot -> the model answers cold. This page lists every prefix we have searched: the model it was found on, what the search was aimed at, how the checkpoint was picked, and how it did on held-out words the search never saw.

Headline

On base models, prefixes aimed at named attention heads work, and for translation and the filter task they act through those heads — but plain answer-only GCG matches or beats them on accuracy, and on phrasings no search saw for three of four word tasks.

Epistemic status: every number comes from a single run unless an entry says otherwise. Claims are about base models only; chat, reasoning and other post-trained models are work in progress.

How to use a prefix

input<prefix> hot ->modelcold
  • Greedy decoding, on the model the entry lists. Base-model entries are plain text; chat entries show the system prompt, the user message and the settings they were run with.
  • Prefixes are model-specific. They did not transfer between models in our tests.
  • Use the Copy button. A leading space (shown as ␣) and every odd character are part of the prefix.
  • Test a prefix outside its format before you rely on it: the search only constrains the one position it scores.
